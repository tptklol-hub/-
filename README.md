# Qoldau — технические условия

Демонстрационный фронтенд корпоративной системы АО «Казахтелеком» для управления жизненным циклом технических условий.

Откройте `index.html` в браузере. Заявки, их статусы и тема сохраняются локально в браузере. Присутствуют интерактивные формы, маршрутизация на уровне демонстрации, реестр, карта-схема, аналитика и CSV-экспорт.

Для промышленного использования потребуются серверная часть, настоящая IAM/SSO-авторизация, API ГИС, документооборот и генерация документов по утверждённым шаблонам PDF/DOCX.
